# 🗺️ Indian State Game

An interactive educational game built with Python and Pandas that challenges users to guess and locate states on a map, tracking their score in real-time.

---

## 🚀 Features

- **Interactive Gameplay:** Type state names to place them directly on the map when guessed correctly.
- **Progress Tracking:** Keeps count of your score out of the total states and prevents duplicate correct guesses.
- **Missed States Export:** Generates a CSV file containing the states you missed so you can study and practice them later.
- **Data Handling:** Powered by Pandas to efficiently process coordinate data and state names.

---

## 🛠️ Built With

- **Python** (Core Logic)
- **Pandas** (Data manipulation and CSV handling)
- **Turtle Graphics** (UI and map rendering)
